# X 粉丝拼图 · 插件安装说明（3 分钟搞定）

1. **下载**：下载 `follower-mosaic-extension.zip`，双击**解压**，得到一个文件夹（不要删它，插件就装在这里）。
2. **打开插件页**：用 Chrome（或 Edge）在地址栏输入 `chrome://extensions` 回车，打开右上角的 **「开发者模式」** 开关。
3. **装进去**：点左上角 **「加载已解压的扩展程序」**，选中刚才解压出来的文件夹 → 完成！点浏览器右上角的拼图图标 🧩，把「X 粉丝拼图」**固定**到工具栏。
4. **使用**：打开 x.com 并登录 → 点插件图标 → 选样式 → 点 **「✨ 生成我的粉丝头像图」** → 等进度条走完 → 点 **「⬇️ 下载图片」**。

> 💡 上架 Chrome 应用商店后，只需要点一下「添加至 Chrome」即可安装，不用上面这些步骤。
>
> 点「生成」后，读取、预览、换样式和下载都在当前 x.com 页面弹出的面板里完成，关闭面板会回到原来的页面。

作者：[@Kuno_he](https://x.com/Kuno_he)

**放心用**：插件不要密码、不需要授权，只在你自己的 x.com 页面里**只读**粉丝列表（默认每页 5 秒、最多 500 人，都可以在弹窗里调），不会发帖、关注或私信；图片在你的电脑上生成，数据不会上传到任何地方。
